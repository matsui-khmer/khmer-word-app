# このフォルダについて

Google Fonts から読み込んでいたフォントを、**自分のサイトに置いたもの**です。
2026-10-29、`css/style.css` の `@import` をやめました。
アプリを開くたびにGoogleへIPアドレスが飛んでいたためです。

**アプリで使っている文字だけに絞り込んであります**（`単語アプリ_Google Play公開/フォントを自前にする.py` で作り直せます）。
単語や画面の文言を増やしたら、**作り直してください。**
絞り込みから漏れた文字は、端末の標準フォントで表示されます（読めますが字面が変わります）。
